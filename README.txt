공감e가득 한국어 시험 체험 V05

실행 방법
1. ZIP 파일을 모두 압축 해제합니다.
2. 폴더 안의 index.html을 Edge 또는 Chrome으로 엽니다.
3. index.html, JavaScript, CSS 파일과 assets 폴더를 함께 보관합니다.
설치나 외부 서버 없이 첨부한 문항·음원으로 실행할 수 있습니다.

제공 범위
- TOPIK I 제102회·제96회: 각 듣기 객관식 1~30번, 30문항·100점.
- KIIP 사전평가: 객관식 1~48번, 48문항.
- KIIP 중간평가: 객관식 1~28번, 28문항.
- KIIP 종합평가 영주용·귀화용: 각각 객관식 1~36번, 36문항.
- TOPIK 읽기와 KIIP 단답·작문·구술 문항도 시험에는 있지만 이번 체험에서는 연습하지 않습니다.
  해당 문항·예시 답안·입력·결과 데이터와 원본 파일은 포함하지 않습니다.
  PDF 문제지·답안도 이번에 제공하는 객관식 범위로 구성했습니다.

기능
- 첨부 웹앱의 Hello 울산 로고·상단 메뉴·하단 구성·원문 이미지·음원을 유지했습니다.
- 시험 선택, 객관식 문제 풀이, 결과·답안의 3개 화면입니다.
- 종합평가 선택 시 영주용·귀화용 드롭다운을 표시합니다.
  1·2·3단계 표시는 기존 서비스 메뉴 순서이며 공식 교육 단계 번호가 아닙니다.
- 객관식 선택 답과 마지막 위치를 시험·회차·용도별로 현재 브라우저에 자동 저장합니다.
- V05 전용 저장 키를 사용합니다. 이전 버전의 진행 상태는 가져오지 않습니다.
- 저장 실패 시 현재 답을 유지하며 같은 화면에서 재시도할 수 있습니다.
- 새로 시작 시 기존 답안 삭제를 확인합니다. 다른 시험의 저장 답은 유지합니다.
- 원본 비율의 그림과 확대창, TOPIK 원본 음원 재생·일시정지·처음부터 다시 듣기를 제공합니다.
- TOPIK 25~26·27~28·29~30번은 음원을 순서대로 재생하고 답은 각각 저장합니다.
- 객관식 정답과 듣기 스크립트는 제출 후 공개합니다.
- 결과 필터는 전체·오답입니다. 미응답은 각 문항에 표시합니다.
- 모바일 1열·키보드 조작·확대창 닫기 후 포커스 복귀를 지원합니다.
- 한국어·영어 UI를 제공합니다. 미등록 언어는 선택할 수 없습니다.
  14개 언어 전체 목록과 번역은 기준 문서에서 별도 확정 대상으로 남아 있습니다.

채점
- TOPIK: 듣기 30문항의 원문 배점을 합산하여 100점 만점으로 표시합니다.
- KIIP: 제공된 학습용 답안 기준의 정답 수입니다. 임의로 100점 환산·합격 판정하지 않습니다.
- 사전평가 45번은 정답 확인 전, 귀화용 11번은 ③·④ 모두 틀린 보기로 검수 전 채점을 보류합니다.
  문항과 보류 사유를 제공하되 정답 수·정답률 분모·오답 목록에서는 제외합니다.
  채점 대상 문항 수: 사전47·중간28·영주용36·귀화용35.
